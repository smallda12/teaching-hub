■ 怎麼用
  學年度首頁先選學習階段裡的學期 → 該學期列出領域 → 點領域看該領域的 5 個單元
  → 點單元開新分頁進入那一站的教學網站。
  各學期頁的網址可以直接帶領域，例如：
    https://smallda12.github.io/teaching-hub/115-1/#自然
    https://smallda12.github.io/teaching-hub/115-2/#語文
    https://smallda12.github.io/teaching-hub/stage1-1/#生活

■ 新增單元之後怎麼更新
  1. 確認新單元已上架、而且 製作完成區\<單元>\線上網址.txt 裡有網址
  2. 第三學習階段（白鯨班）：
       python 產出總入口.py                     （第一學期 → 115-1\index.html）
       python 產出總入口.py --學期二            （第二學期 → 115-2\index.html）
     第二學習階段：
       python 產出總入口.py --階段二            （第一學期 → stage2-1\index.html）
       python 產出總入口.py --階段二 --學期二   （第二學期 → stage2-2\index.html）
     第一學習階段（新班級）：
       python 產出總入口.py --階段一            （第一學期 → stage1-1\index.html）
       python 產出總入口.py --階段一 --學期二   （第二學期 → stage1-2\index.html）
  3. 只加入這次修改的檔案，再 commit、push；不要使用 git add -A，以免帶入其他工作變更。
  🛑 各學期頁 index.html 裡的資料是產生出來的，不要手動編輯。
  🛑 根目錄的 index.html 是純靜態的選單，不是本腳本產生的，要改版面才手動編輯。
  🛑 兩個班級的單元資料夾名稱格式相同，分班依據是素材資料夾 教材規格.py 開頭
     有沒有「第一學習階段」（見 產出總入口.py 的 學習階段()）。

■ 封面圖
  生成封面.py 的六張表：封面／封面二下（白鯨班）、封面新一上／封面新二下（新班級）、
  封面二階一上／封面二階二下（第二學習階段）。
  新班級代號加前綴 new（newchinese01、newchinese01b…），避免與白鯨班同領域同序號撞號。
  第二學習階段代號加前綴 two；第二學期代號尾碼加 b（例如 twope01b）。
    python 生成封面.py 語文 3 --新班          （只重生新班級一上語文第 3 單元）
    python 生成封面.py 語文 3 --新班 --二下
    python 套用封面.py new                     （只壓新班級的，不動既有 90 張）
    python 生成封面.py 語文 1 --二階          （只重生第二學習階段第一學期語文第 1 單元）
    python 生成封面.py 健體 1 --二階 --二下   （只重生第二學習階段第二學期健體第 1 單元）
    python 套用封面.py two                     （只壓第二學習階段的封面）
