■ 怎麼用
  學年度首頁點學期 → 該學期列出 9 個領域 → 點領域看該領域的 5 個單元
  → 點單元開新分頁進入那一站的教學網站。
  各學期頁的網址可以直接帶領域，例如：
    https://smallda12.github.io/teaching-hub/115-1/#自然
    https://smallda12.github.io/teaching-hub/115-2/#語文

■ 教室版 vs 公開版
  從本入口點進去的都是**公開版**（照片上傳自動關閉）。
  老師要用「點點名」的照片功能，請雙擊該單元資料夾裡的 教學網站\index.html。

■ GitHub repo（更新用）
https://github.com/smallda12/teaching-hub
本機 repo 就是本資料夾。

■ 新增單元之後怎麼更新
  1. 確認新單元已上架、而且 製作完成區\<單元>\線上網址.txt 裡有網址
  2. python 產出總入口.py            （第一學期，寫入 115-1\index.html）
     python 產出總入口.py --學期二   （第二學期，寫入 115-2\index.html）
  3. git add -A && git commit && git push
  🛑 115-1\index.html、115-2\index.html 裡的資料是產生出來的，不要手動編輯。
  🛑 根目錄的 index.html 是純靜態的學期選單，不是本腳本產生的，要改版面才手動編輯。
